## 🎯 核心流程图

```
用户添加Widget
    │
    ▼
系统调用 onEnabled()
    │
    ▼
设置AlarmManager (每小时触发)
    │
    ▼
立即调用 onUpdate()
    │
    ▼
启动 HitokotoService
    │
    ▼
┌─────────────────────────┐
│  后台线程执行网络请求   │
│  GET API接口            │
│  解析JSON响应           │
└────────────┬────────────┘
             │
             ▼
    ┌────────────────┐
    │  请求成功？    │
    └───┬────────┬───┘
        │        │
       是│       │否
        │        │
        ▼        ▼
    显示内容   显示错误
        │        │
        └────┬───┘
             │
             ▼
    更新RemoteViews
             │
             ▼
    Widget显示新内容
```

## ⏰ 定时更新流程

```
时间线：
T=0      用户添加Widget → 立即请求API → 显示内容
T=1h     AlarmManager触发 → 请求API → 更新显示
T=2h     AlarmManager触发 → 请求API → 更新显示
T=3h     AlarmManager触发 → 请求API → 更新显示
...

点击刷新：
用户点击Widget → 发送广播 → onReceive() → 立即更新
```

## 🌐 网络请求流程

```
HitokotoService.onHandleIntent()
    │
    ├─► fetchHitokoto()
    │       │
    │       ├─► 创建 HttpURLConnection
    │       ├─► 设置超时（5秒）
    │       ├─► 执行GET请求
    │       └─► 读取响应流
    │           │
    │           ▼
    ├─► 解析JSON
    │       │
    │       ├─► new JSONObject(response)
    │       ├─► 获取 code
    │       ├─► 获取 data.hitokoto
    │       └─► 获取 data.from
    │           │
    │           ▼
    └─► updateWidget()
            │
            ├─► 创建 RemoteViews
            ├─► setTextViewText()
            └─► updateAppWidget()
```

## 🔐 权限使用

```
AndroidManifest.xml 声明的权限：

┌─────────────────────────────────┐
│ INTERNET                        │  → 访问网络API
├─────────────────────────────────┤
│ ACCESS_NETWORK_STATE            │  → 检查网络状态
├─────────────────────────────────┤
│ SCHEDULE_EXACT_ALARM            │  → 精确定时更新
└─────────────────────────────────┘
        │
        ▼
在MIUI系统中还需要：
┌─────────────────────────────────┐
│ 自启动权限                      │  → 允许后台运行
├─────────────────────────────────┤
│ 后台运行权限                    │  → 省电策略无限制
└─────────────────────────────────┘
```
